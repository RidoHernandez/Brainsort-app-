# BrainSort

**BrainSort** is an educational web application focused on learning **competitive programming**, inspired by platforms such as **Duolingo** and **LeetCode**.

The platform aims to teach algorithms, data structures, and problem-solving techniques through an interactive approach, allowing users not only to solve exercises, but also to **visualize and understand how algorithms work step by step**.

## Description

BrainSort was created with the idea of making competitive programming learning more accessible.

The application combines educational content, practical exercises, and visual tools to help users understand concepts such as:

* Algorithms.
* Data structures.
* Algorithmic complexity.
* Problem-solving techniques.
* Competitive programming.

One of the main elements of the platform is the **step-by-step simulation of algorithms**, allowing users to observe how the state of an algorithm changes during its execution instead of simply reading code or theory.

## Main Features

### Library

A section where users can explore content related to:

* Algorithms.
* Data structures.
* Competitive programming techniques.
* Fundamental programming concepts.

### Interactive Learning

The platform follows a progressive learning model, where concepts are presented through theoretical content and practical exercises.

### Algorithm Simulation

Allows users to visualize how different algorithms work **step by step**, making it easier to understand processes that can be difficult to interpret through code alone.

### User Profile

Each user has a profile where they can view information related to their progress and activity within the platform.

### Gamification Approach

The experience is inspired by platforms such as Duolingo, aiming to make competitive programming learning more interactive and progressive.

## Development Methodology

The development of BrainSort began with **user stories**, which were used to identify the main needs and functionalities of the application.

Based on these user stories, **specifications (SPECs)** were created to describe in greater detail the expected behavior of the different functionalities.

**Artificial Intelligence agents** were used as support tools for the creation and refinement of these specifications during the development process.

Afterward, the project was implemented using a **Speak-Driven Development** approach, where communication and the description of functionalities through natural language play an important role in the software development process.

### Development Flow

```text
User Stories
        ↓
      SPECs
        ↓
Artificial Intelligence Agents
        ↓
Design and Planning
        ↓
Speak-Driven Development
        ↓
Implementation
        ↓
Testing and Refinement
```

## Project Objective

The objective of BrainSort is to develop a platform that allows users to learn **competitive programming in a visual, progressive, and interactive way**, combining theory, practice, and algorithm simulation.

The project also aims to explore new approaches to software development supported by **Artificial Intelligence**, using user stories and specifications as the foundation for building the application's functionalities.
